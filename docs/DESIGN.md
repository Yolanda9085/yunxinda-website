# 云心达 · 设计系统文档 (DESIGN.md)

> 基于 Impeccable 设计语言规范，本文档定义云心达品牌网站的可视风格、色彩、排版与组件规则。  
> 所有新增页面与组件应优先遵循本文档中的设定。

---

## 1. 品牌定位 (Brand Lane)

- **类别**: 品牌站（marketing / landing）
- **行业**: 医疗健康 · 智慧健康管理
- **调性**: 专业可信、温暖亲和、科技赋能但不冰冷
- **反参考 (Anti-references)**:
  - ❌ 纯 SaaS CRM 风格（避免过多 dashboard 卡片/数据表格）
  - ❌ 传统医院挂号平台风格（避免冷白色+蓝绿医疗色堆叠）
  - ❌ 健身/运动 App 风格（避免过于活力、霓虹色、大字重体）

---

## 2. 色彩系统

| Token | 色值 | 用途 |
|-------|------|------|
| `--brand-blue` | `#88ccff` | 品牌辅助蓝 |
| `--brand-purple` | `#7755ff` | 品牌主紫 |
| `--brand-mid` | `#8b7fe8` | 渐变过渡 |
| `--primary` | `#7755ff` | 主按钮、链接、强调 |
| `--primary-press` | `#6344e0` | 悬停/按下态 |
| `--ink` | `#0d253d` | 主文字（深蓝调，非纯黑） |
| `--ink-secondary` | `#273951` | 次级文字 |
| `--ink-body` | `#3d5166` | 正文 |
| `--ink-mute` | `#4a5568` | 辅助/弱化文字 (WCAG AA 合规) |
| `--canvas` | `#ffffff` | 页面底色 |
| `--canvas-soft` | `#f6f9fc` | 浅灰分区背景 |
| `--canvas-cream` | `#f5f0e8` | 暖色分区背景 |
| `--hairline` | `#e3e8ee` | 分割线/边框 |

### 色彩使用原则
- 文字永远不直接使用 `#000` 或 `#333`，必须 tint 调色
- 渐变仅用于 Hero 标题文字 (`gradient-text`) 和按钮背景，不泛滥到背景大面积
- 紫色渐变 + 蓝色渐变不应同时大量出现，优先选择一种主导

## 3. 字体排版

| 层级 | 字体 | Weight | 字号 | 字间距 |
|------|------|--------|------|--------|
| H1 / Hero 标题 | PingFang SC, Microsoft YaHei | 500 | clamp(2.125rem, 4.6vw, 3.375rem) | -0.04em |
| H2 / Section 标题 | 同上 | 500 | clamp(2rem, 4.2vw, 3rem) | -0.035em |
| H3 / 卡片标题 | 同上 | 500~600 | 1.0625rem~1.125rem | -0.03em |
| 正文 | 同上 | 400 | 1rem~1.1875rem | 0 |
| 辅助文字 | 同上 | 400 | 0.8125rem~0.875rem | 0 |
| Eyebrow (顶部标签) | 同上 | 400 | clamp(1.0625rem, 1.8vw, 1.25rem) | -0.01em |

### 排版原则
- 标题统一 500 weight，不使用 700 (Bold) 以上的重体
- 中文不使用斜体（italic 仅用于装饰性引文块）
- 行高 1.45~1.65 之间

## 4. 间距与布局

- **基础单位**: 1rem = 16px
- **Section 间距**: 5.5rem 上下
- **卡片 padding**: 1.25rem~1.5rem
- **圆角体系**:
  - 按钮: 999px（全圆角胶囊）
  - 卡片: 16~24px
  - 视觉区域: 12~20px
- **最大内容宽度**: 1200px (`.container`)

---

## 5. 组件规则

### 5.1 按钮
- **主按钮**: 紫色渐变 (`#7755ff`→`#6344e0`)，白色文字，圆角胶囊
- **次按钮**: 无背景，紫色文字 + 悬停下划线
- **玻璃按钮**: 只在 Hero 和 CTA 区域使用 `backdrop-filter`，其他区域使用纯色

### 5.2 卡片
- 默认白底 + `--hairline` 边框 + 极浅阴影
- 悬停效果: translateY(-2px~-4px) + 增强阴影
- **禁止** 卡片内套卡片（反模式）
- 图标不使用彩色方块容器包裹（反模式）— 直接使用纯 SVG 图标

### 5.3 Glass（玻璃拟态）
- **保留区域**: Header 背景、Hero 浮动 badge、CTA 按钮
- **已移除区域**: workflow-step、feature-visual、testimonial-card、product-tab-panel、bento-wrap
- 最多 3-4 处同时存在 glass 效果，避免性能问题

---

## 6. 动效规范

- **缓动函数**: `cubic-bezier(0.25, 0.46, 0.45, 0.94)` 或 `ease-out`
- **过渡时长**: 200ms~300ms
- **禁止**: bounce / elastic 弹性动画（显得过时）
- **浮动动画**: `cubic-bezier(0.45, 0, 0.55, 1)`，3.4s 周期，位移不超过 6px
- **入场动画**: `opacity` + `translateY(20px→0)`，600ms ease-out
- 支持 `prefers-reduced-motion: reduce`

---

## 7. 无障碍与质量

- 所有交互元素最小触摸目标: 44×44px（移动端标准）
- 文字对比度: WCAG AA 级（4.5:1 以上）
- 图片必须有 `alt` 属性
- 表单输入框有 `label` 关联
- 支持键盘导航（focus-visible）
