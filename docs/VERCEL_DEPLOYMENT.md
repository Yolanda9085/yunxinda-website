## 🚀 现在部署到 Vercel（2 步）

### 第 1 步：访问 Vercel
https://vercel.com

### 第 2 步：导入项目
1. 点击 **"Add New..."** → **"Project"**
2. 点击 **"Import Git Repository"**
3. 授权 GitHub 账号（如果需要）
4. 找到 **`yunxinda-website`** 仓库
5. 点击 **"Import"**

### 第 3 步：配置和部署
1. **Project Name**：`yunxinda-website`（已自动填充）
2. **Environment**：使用默认配置
3. 点击 **"Deploy"**
